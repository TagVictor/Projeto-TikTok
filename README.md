## 📖 Sobre o Projeto

O **Projeto TikTok - ADS** é um projeto acadêmico desenvolvido por estudantes do curso de **Análise e Desenvolvimento de Sistemas (ADS)**, iniciado no **2º semestre**, em **03/09/2026**.

O projeto consiste no desenvolvimento de uma interface inspirada na plataforma TikTok, tendo como finalidade colocar em prática os conhecimentos adquiridos durante a formação acadêmica.

---

## 🎯 Objetivo

O principal objetivo do projeto é proporcionar aos estudantes uma experiência prática de desenvolvimento de sistemas, aplicando os conhecimentos adquiridos durante o curso de **Análise e Desenvolvimento de Sistemas**.

A proposta também busca estimular o trabalho em equipe, a organização do projeto e o desenvolvimento de uma interface inspirada em uma plataforma digital amplamente conhecida.
