# 🎵 Projeto TikTok

> Projeto acadêmico desenvolvido por estudantes do curso de Análise e Desenvolvimento de Sistemas (ADS).

---

## 📖 Sobre o Projeto

O **Projeto TikTok** é um projeto acadêmico desenvolvido por estudantes do curso de **Análise e Desenvolvimento de Sistemas (ADS)** durante o **2º semestre da faculdade**.

O desenvolvimento foi iniciado em **03/09/2026**, com o objetivo de aplicar, na prática, os conhecimentos adquiridos ao longo da formação acadêmica.

---

## 📝 Descrição

O projeto consiste no desenvolvimento de uma interface inspirada na plataforma **TikTok**, utilizando como referência sua proposta de apresentação e interação com conteúdos digitais.

A atividade busca proporcionar aos estudantes uma experiência prática de desenvolvimento, permitindo trabalhar em equipe e transformar os conhecimentos adquiridos em sala de aula em um projeto aplicado.

---

## 🎯 Objetivo

O principal objetivo é **aplicar na prática os conhecimentos adquiridos durante o curso de Análise e Desenvolvimento de Sistemas**, desenvolvendo uma interface inspirada no TikTok.

Além disso, o projeto busca estimular:

- Trabalho em equipe;
- Organização e desenvolvimento de um projeto;
- Aplicação prática dos conhecimentos acadêmicos;
- Desenvolvimento de interfaces;
- Experiência com desenvolvimento de sistemas.

---

## 🚀 PRINCIPAIS FUNCIONALIDADES

As principais funcionalidades do projeto estão relacionadas à proposta de reprodução e inspiração da interface do TikTok.

- Interface inspirada na plataforma TikTok;
- Estrutura visual baseada na experiência de utilização da plataforma;
- Organização de conteúdos em uma interface de vídeos;
- Elementos de interação inspirados em redes sociais;
- Navegação pela interface do projeto.

> **Observação:** as funcionalidades podem ser atualizadas conforme o desenvolvimento do projeto.

---

## 💻 TECNOLOGIAS UTILIZADAS

## Tecnologias:
> Desenvolvimento Mobile: Swift para o aplicativo iOS e Kotlin para o aplicativo Android
> Backend e Serviços: Node.js
> Processamento de Dados: Apache Spark
> Banco de Dados e Armazenamento: Bancos relacionais com SQL e NoSQL
> Inteligência Artificial: Algoritmos proprietários de aprendizado de máquina (Machine Learning)

---

## ⚙️ REQUISITOS PARA UTILIZAÇÃO

- Android Sistema Operacional: Android 5.0 (Lollipop) ou superior. Armazenamento: Pelo menos 102 MB para o download inicial
- No iOS (iPhone / iPad)Sistema Operacional: iOS 9.3 ou superior. Armazenamento: Cerca de 300 MB para a instalação inicial.
- Computador ou notebook;
- Navegador de internet atualizado;
